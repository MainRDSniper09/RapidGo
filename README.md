# RapidGo - Pipeline Big Data End-to-End

Este repositorio contiene la implementación final del pipeline de datos para RapidGo, abordando el reto de orquestar un flujo de procesamiento de streaming y batch para analítica de tiempos de entrega y preparación de pedidos.

## 🚀 Cómo ejecutar el proyecto

Para levantar el entorno completo con todos los servicios (Kafka, Spark, Airflow), ejecuta el siguiente comando en la raíz del proyecto:

```bash
docker compose up -d
